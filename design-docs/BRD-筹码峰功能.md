## 1. 背景与目标

在 Tick Stock Panel（下称 TSP）中，基于筹码峰（CYQ / 移动成本分布）战法构建量化能力。筹码分布刻画"当前流通筹码在各价格区间的成本堆积"，是判断主力成本、套牢盘/获利盘、单峰密集形态的核心工具。

**目标**：先用 TSP 已有的前复权行情与换手率，离线预计算每只股票的筹码分布与派生因子，并在"点击个股查看"时同步展示筹码峰图；随后基于筹码峰形态做全市场筛选（最终目标）。

## 2. 术语定义

| 术语 | 定义 |
| --- | --- |
| 筹码分布（CYQ） | 把流通筹码按其历史成交价格区间加权堆积得到的分布，随换手逐日"移动" |
| 换手率（turnover_rate） | 当日成交量占流通股本的比值。**TSP enriched 表为百分数口径（5.0 = 5%）** |
| 衰减系数（decay） | 放大换手以近似"自由流通盘真实换手"，默认 1.0 |
| 前复权 | 以最新价为基准回溯调整历史价格，消除除权除息跳空 |
| 价格网格 / bins | 把价格轴切成 N 个固定箱，筹码分布即落在这些箱上的直方图 |
| 获利盘比例 | 成本低于现价的筹码占比 |
| 90% 成本集中度 | 覆盖 90% 筹码的价格区间宽度相对其价格水平的比值 |

## 3. 范围

**范围内**：

1. 单只股票筹码分布计算（三角形分布递推）与因子提取。
2. 全市场筹码分布/因子的落盘与逐日增量更新（盘后触发）。
3. 筹码查询 API。
4. 个股预览对话框内"筹码峰"视图展示。
5. （后续）基于筹码形态的全市场筛选策略。

**范围外**：

- Tick 级逐笔成交、分钟级筹码（过度采样，A 股逐笔也不可得）。
- 真实持仓明细（A 股不可得）。
- 实时盘中逐 tick 更新筹码（盘后更新即可）。

## 4. 使用场景与目标用户

| 场景 | 用户 | 结果 |
| --- | --- | --- |
| 点击自选/选股列表中的股票查看筹码峰图 | 量化散户 | 个股预览对话框切换到"筹码"视图，看到分布图 + 关键因子 |
| 盘后批量更新全市场筹码 | 系统（盘后管道） | 所有股票筹码分布与因子落盘 |
| 用筹码形态筛选可买股票 | 量化散户 | 选股页按单峰密集/低位/获利盘区间等条件选出标的，可回测 |

## 6. 非功能需求（NFR）

| 编号 | 需求 |
| --- | --- |
| NFR-1 | 单只股票 10000 根日 K 的筹码计算 < 1s；全市场批量 < 10min |
| NFR-2 | 集中度等因子与同花顺筹码峰视觉判断误差 < 5%（人工抽检） |
| NFR-3 | 所有数值 float64；单元、复权、交易日口径与 `CONTRIBUTING.md §3` 一致 |
| NFR-4 | 复用现有 enriched 数据与 generation 发布机制，不平行实现第二套数据/缓存 |
| NFR-5 | 核心算法为纯函数，带类型注解、docstring 与单元测试 |

## 7. 核心算法规格

### 7.1 递推公式

```
当日筹码分布 = 昨日筹码分布 × (1 − turnover_fraction × decay) + 当日新筹码
```

其中 `turnover_fraction = turnover_rate / 100`（百分数 → 小数），
`t_decay = clamp(turnover_fraction × decay, 0, 1)`（防止 >1 出现负保留比例）。

### 7.2 三角形分布（当日新筹码，同花顺默认）

- 以 `close` 为顶点，权重 `weight(price) = max(0, 1 − |price − close| / (high − low))`。
- 归一化后乘以 `t_decay` 得到当日新筹码质量。
- `high == low`（一字板）退化为 delta 函数：全部落在最接近 `close` 的 bin。

### 7.3 衰减系数

- 默认 `decay = 1.0`（朴素假设全部流通股自由换手）。
- 参数贯穿整个调用链，后续可接入股东数据动态校准（`decay = 1/(1 − top10 持股比)`）或流通市值分档映射。

### 7.4 回溯窗口选择

从最新交易日向前累计 `turnover_fraction`，直到累计 ≥ `min_cum_turnover`（默认 3.0，即 3 倍流通盘）或达到 `max_lookback`（默认 2500 个交易日）。窗口过短会丢失早期套牢盘、造成虚假集中。

### 7.5 价格网格

- 网格基于**单只股票自身的窗口**，非全市场共享绝对刻度。
- `grid_min = max(min(low_window) × (1 − padding), 1e-6)`，`grid_max = max(high_window) × (1 + padding)`，`padding` 默认 3%。
- `price_grid = linspace(grid_min, grid_max, bins=100)`，**递推期间固定不变**。

### 7.6 归一化

递推结束后，若分布总量 > 0，归一化到总量 = 1。所有因子均为比例，与绝对流通股本无关（故无需 `float_shares`）。

## 8. 因子定义

| 因子 | 公式 | 口径 |
| --- | --- | --- |
| `profit_ratio` | `Σ(dist[grid ≤ 现价]) / Σ(dist)` | 获利盘比例，[0,1] |
| `concentration_90` | `(P95 − P5) / (P95 + P5)`，P5/P95 为累计筹码 5%/95% 分位对应价格 | 90% 成本集中度，无量纲 |
| `avg_cost` | `Σ(price_grid × dist) / Σ(dist)` | 平均成本（前复权价） |
| `avg_cost_deviation` | `(现价 − avg_cost) / avg_cost` | 平均成本偏离度，无量纲 |
| `single_peak_ratio` | 主峰 basin 内筹码量 / 总筹码量 | 单峰形态强度，[0,1]（简化版） |
| `single_peak_width` | `(主峰 basin 右边界价 − 左边界价) / 现价` | 单峰宽度，无量纲（简化版） |
| `is_low_position` | `现价 < 近 low_window(默认 250) 交易日 close 的 30% 分位` | 低位标志，bool |

> 单峰识别为简化实现：对分布做边缘填充滑动平均（`smooth_width=3`），取全局最大峰，向两侧走到局部极小或边缘得到 basin。形态学的进一步优化（高斯平滑、半高宽、多峰合并）留待后续。

## 9. 数据需求与复用

| 需要 | 来源 | 说明 |
| --- | --- | --- |
| 前复权 high/low/close | enriched 表 | `open/high/low/close` 已为前复权价 |
| 换手率 | enriched 表 `turnover_rate` | 百分数口径，已处理"历史股本优先" |
| 流通股本 | **不需要** | 因子均为比例，归一化基准任意 |
| 本地历史读取 | Parquet / repository | 走 provider/repository 抽象，不硬编码 TickFlow |

**严禁**直接调用 `tickflow` SDK 批量拉取、自行复权、自行用 `volume/float_shares` 算换手率（违反 `CONTRIBUTING.md §4`）。

## 10. 架构与集成

### 10.1 文件落点

| 文件 | 职责 | 阶段 |
| --- | --- | --- |
| `backend/app/indicators/chip.py` | 核心算法纯函数 | 1 |
| `backend/app/services/chip_pipeline.py` | 全市场计算 + 落盘 + 增量 | 2 |
| `backend/app/api/chip.py` | 查询 API | 3 |
| `frontend/src/components/chip/ChipDistributionChart.tsx` | 筹码图组件 | 4 |
| `frontend/src/lib/api.ts` / `queryKeys.ts` | API 封装 + 查询键 | 4 |

### 10.2 落盘 schema

`data/chip_distribution/all.parquet`，每行一只股票：

```
symbol, date, price_grid[100], distribution[100],
profit_ratio, concentration_90, avg_cost_deviation,
single_peak_ratio, single_peak_width, is_low_position, avg_cost
```

直接存 `price_grid` 数组（100 个价格刻度），消除前端还原价格轴的歧义。

### 10.3 发布与调度

- 发布走现有 `EnrichedPublication` 的 generation + 原子替换机制。
- 挂在 15:30 盘后管道上，随数据更新触发。

### 10.4 慢路径（增量更新的必要分支）

| 触发条件 | 处理 |
| --- | --- |
| 除权除息（adj_factor 变化，前复权价全历史变动） | 该股全量重算 |
| 现价越出网格边界（含安全余量） | 该股 re-base（重设网格 + 重算） |

两条慢路径**复用初始化时的全量计算代码**，只对少数受影响股票执行，日常快路径为"逐股迭代一根 K 线"。

## 12. 风险与缓解

| 风险 | 缓解 |
| --- | --- |
| 百分数/小数口径混淆 | 参数显式命名 + docstring + 单测 |
| 除权后增量失效 | adj_factor 触发全量重算 |
| 网格越界丢筹码 | 越界触发 re-base |
| 回溯过短造成虚假集中 | 累计换手 ≥ 3 倍窗口 + 上限保护 |
| 单峰识别粗糙 | 标记为简化版，后续优化 |
| 性能不达标 | NumPy 向量化 + 按 symbol 并行 |
| 换手率缺失（NaN） | 按 0 处理（当日不衰减、不新增），fail-closed |
